# Q3 refresh gate

As of October 16, 2026, this project has not obtained a Q3 10-Q. Do not label the estimates as reported quarter-end figures. No recurring automation is installed.

When the filing becomes available:

1. Record its URL, filing date, balance-sheet date and the cover-page share-count date separately.
2. Replace preferred counts at quarter-end. Roll forward only actions after that quarter-end to the model’s chosen common observation date; do not subtract pre-quarter-end buybacks again.
3. Replace Class A/B counts and awards. Reconcile shares from the cover date through the new observation date; avoid the straddling-week double count in the current estimate.
4. Update each note’s outstanding principal, conversion terms and puts. Use current adjusted conversion terms if the filing reports changes.
5. Refresh Reserve, USD Cash, common ATM capacity and buybacks from the same dated weekly filing. USD Cash excludes ordinary operating cash.
6. Refresh market prices and FX on a consistent observation basis. Use the issuer’s Friday fixing for an exact issuer-metric reconciliation; label any ECB substitute.
7. Reconcile the current annual charge estimate to management’s dated estimate. Explain count, rate, FX and timing differences separately.
8. Recalculate all sheets and both native Data Tables in desktop Excel. Run the scenarios and Goal Seek exercise in `excel-review.md`.
9. Update calculator constants, textbook, source register and November 10 draft together. Re-run calculator/workbook comparisons and record file hashes.
